1. 상품권 정보와 보관
상품권 이미지 사본, 이름·사용기한·바코드·메모, 잔액·사용 내역과 알림 설정은 상품권 관리와 알림을 위해 휴대폰의 앱 전용 저장공간에 보관합니다. 글자·바코드 인식도 기기에서 처리합니다. 회원가입은 없으며, 상품권 내용은 운영자 서버에 업로드하거나 광고 요청에 전달하지 않습니다.

상품권을 삭제하면 해당 정보와 더 이상 사용하지 않는 이미지 사본을 지웁니다. 앱 데이터 삭제나 앱 제거 시 내부 저장 정보가 삭제됩니다. 갤러리의 원본 파일은 삭제·수정하지 않습니다. 자동 백업·기기 간 동기화는 제공하지 않으며, 운영자는 기기에만 있는 상품권을 원격으로 조회·복구할 수 없습니다.

2. 사진과 알림 권한
사진·파일 선택기나 공유로 사용자가 선택한 이미지만 읽습니다. 전체 갤러리·카메라·연락처·문자·위치 권한은 요청하지 않습니다. 알림 표시와 정확한 알림 권한은 사용기한 알림에 사용하며, 허용하지 않아도 상품권 관리는 가능합니다.

3. Google 서비스와 광고
배너 광고에는 Google AdMob을, 문자·바코드 인식에는 Google ML Kit를 사용합니다.
• AdMob: 광고 제공·측정, 분석, 부정행위 방지를 위해 IP 주소(대략적 위치 추정 가능), 앱·광고 상호작용, 성능·진단 정보, 광고 ID·앱 세트 ID 등의 식별자를 수집·공유할 수 있습니다.
• ML Kit: 진단·사용 분석을 위해 설치별 식별자, 기기·앱 정보, 기능 사용·성능·오류, 입력 형식·크기 등의 기술 정보를 Google에 전송할 수 있습니다. 인식할 이미지 내용은 기기에서 처리합니다.

Google SDK의 데이터 전송은 HTTPS/TLS로 암호화됩니다. 데이터는 국외 서버에서 처리될 수 있으며 Google의 정책에 따라 보관·삭제됩니다.
Google 개인정보처리방침: https://policies.google.com/privacy
AdMob 데이터 안내: https://developers.google.com/admob/android/privacy/play-data-disclosure
ML Kit 데이터 안내: https://developers.google.com/ml-kit/android-data-disclosure

지역·동의 상태에 따라 Google의 동의 메시지가 표시됩니다. 선택 변경이 필요한 경우 설정에 표시되는 ‘광고 개인정보 선택’에서 변경할 수 있습니다. 광고 ID는 휴대폰 설정에서 재설정·삭제할 수 있습니다. 맞춤형 광고를 거절해도 모든 SDK 통신이 중단되는 것은 아닙니다.

4. 외부 지도와 문의
매장 검색을 누르면 브랜드·매장 검색어가 외부 지도 앱 또는 웹 서비스에 전달됩니다. 위치 정보 처리는 해당 서비스의 권한·정책을 따릅니다. 기프트 알리미가 위치를 수집하지는 않습니다.
이메일 문의 시 이메일 주소와 제공한 내용을 답변·문제 해결에 사용하고, 해결 후 지체 없이 삭제합니다. 법령상 보관 의무가 있으면 해당 기간을 따릅니다. 개인정보 열람·정정·삭제 등은 위 이메일로 문의할 수 있습니다.
