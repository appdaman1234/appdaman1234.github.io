여기교통은 저장한 장소 주변의 버스·지하철 도착 정보를 보여주는 앱입니다. 별도의 회원가입은 없으며 Google AdMob 배너 광고가 포함됩니다. 현재 제공 버전에서는 실제 결제·구매 복원 기능을 제공하지 않습니다. 아래는 위치, 교통 조회, 문의 및 광고 정보 처리에 관한 안내입니다.

1. 처리하는 정보와 목적

  • 장소와 앱 설정: 장소 이름, 좌표, 주소, 정류장·역 및 노선 선택, 위젯 설정과 조회 횟수를 기기 안에 저장합니다. 가까운 장소 판단은 기기에서 합니다. 장소 목록 전체를 운영자 서버에 업로드하지 않습니다. Android 시스템 백업이 켜져 있으면 사용자의 백업 계정에 장소 설정 등이 보관될 수 있습니다.
  • 위치와 교통 조회: 위치 권한을 허용하고 현재 위치 기능을 실행하면 현재 위치를 한 번 확인하여 가까운 장소를 선택합니다. 지속적인 위치 추적은 하지 않습니다. 주변 버스 정류장을 검색할 때 검색 중심 좌표를 운영자의 Cloudflare 서버로 전송하고, 서버에 포함한 공개 정류소 목록으로 거리 검색을 수행합니다. 이 검색 좌표를 서울시 원천 API로 전달하지 않으며 운영자 데이터베이스에 검색 좌표나 이동 이력을 저장하지 않습니다. 버스·지하철 도착 및 우회·미정차 조회에는 정류장 번호, 노선 번호 또는 역 이름 등이 서버와 교통정보 제공기관으로 전송됩니다.
  • 지도·주소: 지도 표시를 위해 지도 화면의 영역과 IP 주소 등 접속 정보가 NAVER Maps에 전달될 수 있습니다. 입력한 주소 검색어와 좌표의 주소 변환에는 Android 기기의 주소 검색 제공자가 사용됩니다. 지도·주소 검색을 실행하지 않으면 해당 기능에서의 전송은 발생하지 않지만 새로운 장소를 지정하는 방법이 제한될 수 있습니다.
  • 개발자 문의: 사용자가 문의 화면에서 보내기를 누르면 문의 종류, 제목·내용, 앱 버전, 접수번호, 선택 입력한 회신 이메일을 처리하여 답변과 문제 해결에 사용합니다. 위치와 장소 설정은 자동 첨부하지 않습니다. 이메일을 입력하지 않아도 접수되지만 답변을 받기 어렵습니다.
  • 결제 기능: 현재 제공 버전은 실제 결제·구매 복원을 비활성화하고 있으며 구매 확인을 위한 토큰을 운영자 서버로 전송하지 않습니다. 결제 기능을 제공하게 되면 처리 항목과 목적 등을 본 방침에 반영하여 안내합니다.
  • 배너 광고: Google AdMob SDK는 광고 표시, 측정 및 부정 사용 방지를 위해 IP 주소(대략적인 위치 추정에 이용), 광고 상호작용, 진단 정보, 광고 ID 등 기기·계정 식별자를 처리할 수 있습니다. 앱은 비개인 맞춤 광고를 요청하며 장소 이름이나 좌표를 광고 요청에 직접 넣지 않습니다. 비개인 맞춤 광고도 정보 처리가 발생합니다. 필요한 지역의 동의는 Google UMP 화면에서 받으며, 제공되는 경우 메뉴의 ‘광고 개인정보 설정’에서 변경할 수 있습니다. 현재 버전은 Basic·Pro 설정과 관계없이 배너가 표시될 수 있습니다.
  • 서비스 보안: 서버 연결 시 IP 주소, 요청 경로 등 통신 정보가 처리됩니다. 운영자 데이터베이스에는 남용 방지를 위한 IP 해시, 요청량, 문의 접수 상태 등을 최소한으로 저장합니다. 원문 IP와 문의 본문을 이 데이터베이스에 저장하지 않습니다.

2. 처리 업체와 국외 처리

Cloudflare, Inc.의 서버·네트워크에서 교통 조회, 문의 전달 및 최소 기록 보관을 처리합니다. Google LLC의 Gmail로 문의를 수신하고 AdMob·UMP로 광고와 동의를 처리합니다. NAVER Cloud의 Maps와 기기의 주소 검색 제공자는 지도·주소 기능에 사용됩니다. 교통 조회는 서울시 교통정보 제공 서버를 이용합니다.

Cloudflare와 Google은 미국에 본사를 둔 글로벌 서비스이며, 연결 또는 문의·광고 요청 때 정보가 암호화된 통신을 통해 해외 인프라에서 처리될 수 있습니다. 실제 처리 위치와 서비스 자체 보관 기간은 각 제공자의 운영 및 정책에 따릅니다. 기능별 전송 항목과 목적은 위 1항과 같습니다. 문의 내용은 보내기를 누르기 전에는 전송되지 않으며, 선택 기능을 사용하지 않거나 앱 사용을 중단하여 해당 전송을 중단할 수 있습니다. 이전·처리 관련 요청은 운영자 이메일로 문의할 수 있습니다.

3. 보관과 삭제

  • 기기 안의 장소·위젯 설정과 사용량 기록은 사용자가 해당 설정을 삭제하거나 앱 데이터를 지울 때까지 보관하며, 조회 한도는 한국 시간 날짜에 따라 일일 단위로 갱신됩니다. 시스템 백업 사본은 사용자의 Android 백업 설정에서 관리합니다.
  • 문의 메일은 처리 완료 후 90일 이내에 운영자가 메일함과 휴지통에서 삭제합니다. 답변을 보낸 순간 자동 삭제되는 기능은 없습니다. 미해결 문의는 처리 완료까지 보관하며, 조기 삭제를 요청할 수 있습니다.
  • 문의 접수번호·내용 해시·처리 상태는 접수 후 90일을 기준으로 서버 정리 시 삭제합니다. IP 해시 속도 제한 기록은 제한 만료 후 정리하며, 요청량 집계는 다음 월의 정리 시 삭제합니다. 서버 정리는 다음 요청이 들어올 때 실행됩니다.
  • Google 등이 처리하는 광고·진단 정보는 각 제공자의 정책에 따라 보관·삭제됩니다.
  • 법령에 따라 보관이 필요한 거래·분쟁 기록은 해당 의무 기간에 한해 별도로 보관하고 목적 달성 뒤 삭제합니다.

4. 선택과 권리 행사

위치 권한은 Android 앱 권한 설정에서 철회할 수 있습니다. 허용하지 않으면 가까운 장소 자동 선택 등 위치 기능이 제한되지만 직접 장소를 설정할 수 있습니다. 광고 ID 삭제·재설정은 Android 개인정보 설정에서 할 수 있습니다. 정보 열람, 정정, 삭제, 처리 정지 및 동의 철회는 appdaman1234@gmail.com으로 요청하세요. 문의 접수번호 등 필요한 최소 정보로 본인 확인 후 처리하며, 법정 보관 의무가 있는 경우 그 사유를 안내합니다. 계정이 없는 앱이므로 별도의 회원 탈퇴 절차는 없습니다.

5. 보호 조치와 변경

앱과 운영자 서버는 HTTPS를 사용하며 교통 API 비밀키는 서버의 Secret 저장소에 보관합니다. 단, 일부 서울시 버스·지하철 원천 API 구간은 제공되는 HTTP 연결을 사용하여 정류장·노선 식별자, 역명 등 조회 조건과 제공기관 인증키가 그 구간에서 암호화되지 않을 수 있습니다. 주변 정류장 검색 좌표와 문의 내용은 이 원천 HTTP 연결로 전송하지 않습니다.

운영자는 접근을 제한하고 최소 기록만 보관합니다. 방침이 바뀌면 이 페이지와 앱 내 방침을 갱신하며, 새로운 동의가 필요한 변경은 해당 기능에서 별도로 안내합니다.
